# Dashboard Assets

The four `dashboard-*-synthetic.png` files are publication-ready portfolio examples generated from the verified dashboard layout.

## Data boundary

- All business values are synthetic and intentionally coherent across pages.
- The client identity is the placeholder `EXAMPLE CLIENT`.
- Customer, product, supplier, category, date, and payment-status labels are generic.
- No production URL, connection value, tenant identifier, email, or credential is shown.
- These images demonstrate report design and analytical structure; they do not represent actual company performance.

## Publication rule

Only files ending in `-synthetic.png` are approved for the public portfolio. The four numbered source screenshots are local edit inputs and are explicitly ignored by Git.

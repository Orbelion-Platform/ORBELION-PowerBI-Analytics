# DAX Measure Catalog

The private semantic model contains 36 verified measures organized into six display folders. Formulas are provided in `examples/measures.dax`.

## 01 Executive

- Ventas Netas
- Costo de Ventas
- Utilidad Bruta
- Margen Bruto %
- Gastos Totales
- Utilidad Operativa
- Valor Inventario
- Ticket Promedio
- Crecimiento Ventas %

## 02 Sales

- Cantidad Vendida
- Clientes Activos
- Productos Vendidos
- Venta Promedio por Cliente
- Descuento Total
- Descuento %
- Precio Promedio
- Transacciones

## 03 Expenses

- Gasto Promedio
- % Gastos sobre Ventas

## 04 Purchases

- Compras Totales
- Cantidad Comprada
- Compra Promedio
- Costo Unitario Promedio
- Proveedores Activos
- Productos Comprados

## 05 Inventory

- Cantidad Movida
- Costo Unitario Promedio Inventario

## 06 Time Intelligence

- Ventas Mes Anterior
- Ventas Año Anterior
- Ventas MTD
- Ventas YTD
- Variación Ventas %
- Gastos Mes Anterior
- Variación Gastos %
- Compras Mes Anterior
- Variación Compras %
